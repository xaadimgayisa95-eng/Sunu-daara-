# سونو دارا · Sunu Daara

نموذج تجريبي لمنصة المدارس القرآنية في السنغال (واجهة جوال).

## الملفات (ارفعها كما هي، دون أي تعديل)
- `index.html` — الصفحة الرئيسية
- `style.css` — التنسيق
- `app.js` — منطق التطبيق
- `logo.jpg` — الشعار
- `splash.jpg` — شاشة الافتتاح

## الرفع إلى GitHub من الهاتف (دون ذكاء اصطناعي)
1. افتح github.com وسجّل الدخول، ثم اضغط **New repository**، سمِّه `sunu-daara`، واتركه **Public**.
2. داخل المستودع: **Add file ← Upload files**، ثم اختر الملفات الخمسة أعلاه (وهذا الملف أيضًا) من هاتفك، ثم **Commit changes**.
   - لا ترفع ملف الزيب: GitHub لا يفكّه. فُكّه أولًا في هاتفك ثم ارفع الملفات.
3. لنشره كموقع: **Settings ← Pages**، واختر Branch: `main` والمجلد `/ (root)`، ثم **Save**.
4. بعد دقيقة يظهر الرابط: `https://اسم-حسابك.github.io/sunu-daara/`

## ملاحظات
- كل البيانات والصور تجريبية، ولا يوجد حفظ حقيقي.
- الخط يُحمَّل من Google Fonts، فيلزم إنترنت لرؤية الخط الأصلي.
